JosaFX Signal Advisor v3

This is a signal-only PWA. It does not place trades.

Features:
- Multi-timeframe analysis: 4H, 1H, 15M and selected entry timeframe
- BUY / SELL / WAIT
- Entry, SL, TP1, TP2
- EMA20/50, RSI14, MACD, ATR14
- Recent support/resistance
- Signal history stored locally
- Installable PWA shell
- JosaFX license field prepared for a secure server-side license system

Important:
1. A Twelve Data API key is required for live market data.
2. Do not publish your API key inside the HTML source.
3. The license field is NOT a secure license server by itself. For production use, connect it to a backend that verifies keys, expiry and revocation.
4. The app is a rule-based analysis tool, not a guarantee of profit.
